Problem Statement & Objectives

The Challenge

  • Fragmented Materials: Disconnected syllabi, lecture slides, and university calendars.
  • Scheduling Conflicts: Overlapping exam weeks, misaligned pacing, and uncoordinated holidays.
  • Manual Synthesis: Hours spent creating study guides and mock quizzes.
  • Compute Demands: Heavy vector embeddings and LLM reasoning exceed client-side capacities.

The Cloud Solution

  • Stateless Microservices: Elastic containerized backend hosted on Microsoft Azure.
  • Autonomous Multi-Agent AI: LangGraph orchestrator parsing PDFs and conflict-free schedules.
  • Semantic Vector RAG: PostgreSQL Flexible Server + pgvector for sub-second similarity lookups.
  • Global Edge Delivery: Next.js on Vercel Edge for sub-50ms user response.

Containerization & Multi-Agent Workflow

Docker Containerization

  • Lightweight Debian Base: python:3.12-slim for minimal attack surface.
  • Multi-stage Caching: Cached wheel builds and isolated dependency management.
  • Docker Compose: Local parity for PostgreSQL + pgvector and FastAPI.
  • Health Monitoring: Dedicated /health probe endpoint for container liveness.

LangGraph Multi-Agent Engine

  • Extraction Agent: Normalizes PDF syllabus and dates into JSON schemas.
  • Scheduler Agent: Allocates 15 weeks, detects break collisions, and slots midterms.
  • Retrieval Agent: Cosine similarity search over 1536-dim vectors.
  • Quality Control Agent: Hallucination check with automated retry loop.

Automated CI/CD & OIDC Cloud Security

Secretless OIDC Authentication

  • Zero static passwords stored in GitHub Secrets.
  • Cryptographic JWT exchange via Microsoft Entra ID.
  • Role-Based Access Control (RBAC) with Least Privilege.
  • Temporary, ephemeral permissions during workflow execution.

GitHub Actions Pipeline (deploy-azure.yml)

  • Triggers on push to main branch.
  • Logs in via azure/login@v2.
  • Builds and pushes Docker image to ACR.
  • Updates cloud settings & executes rolling deployment.

Results, Cloud Metrics & Conclusion
